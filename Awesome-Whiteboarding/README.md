# Awesome-Whiteboarding

## Top Whiteboarding Tools Ecosystem



**Curated List of SaaS/Commercial Products & Open-Source GitHub Projects**  

*Focused on Collaborative Digital Whiteboards, Infinite Canvas, Brainstorming, Diagramming & Visual Collaboration*  

**Last updated: August 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **Whiteboarding**. These tools provide infinite canvases for real-time or async visual collaboration — brainstorming, diagramming, workshops, wireframing, and sticky-note style ideation.



**Examples** include Miro, Mural, FigJam, Lucidspark, Microsoft Whiteboard, Whimsical, Stormboard, Conceptboard, Excalidraw, and Collaboard (the category leaders).



**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosted or browser-based open whiteboards — ideal for teams that want privacy, no per-seat fees, and full control over their visual collaboration data.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## Open-Source GitHub Projects



- **[Excalidraw](https://github.com/excalidraw/excalidraw)**  

  The leading open-source virtual whiteboard (MIT). Hand-drawn style diagrams, wireframes, and sketches with real-time collaboration (end-to-end encrypted), offline support, libraries, and easy self-hosting or embedding.



- **[AFFiNE](https://github.com/toeverything/AFFiNE)**  

  Open-source, local-first workspace that combines whiteboard/canvas capabilities with documents and knowledge management in one privacy-focused tool.



- **[diagrams.net / draw.io](https://github.com/jgraph/drawio)**  

  Powerful open-source diagramming tool (Apache 2.0) widely used for technical diagrams, flowcharts, architecture, and whiteboard-style canvases. Fully self-hostable.



- **[tldraw](https://github.com/tldraw/tldraw)**  

  High-quality infinite canvas library and whiteboard. Note: licensing has evolved; check current terms for production/commercial use versus the visible source.



- **[Penpot](https://github.com/penpot/penpot)**  

  Open-source design and collaboration platform with canvas capabilities suitable for design-oriented whiteboarding and prototyping. Fully self-hostable.



- **[WBO / Whiteboard Online](https://github.com/lovasoa/whitebophir)**  

  Lightweight, open-source collaborative whiteboard that runs in the browser with minimal setup and real-time multi-user drawing.



- **[Drafft.ink](https://github.com/PatWie/drafft-ink)**  

  High-performance open-source infinite canvas whiteboard built with Rust and WebGPU, supporting live collaboration and self-hosting.



- **[OpenBoard](https://github.com/OpenBoard-org/OpenBoard)** and other education-focused boards  

  Open-source interactive whiteboard software originally aimed at classrooms but usable for general collaborative drawing and annotation.



### Additional Strong Open-Source Options



- Browser-based sketch tools and infinite canvas experiments available on GitHub.

- Integrations of Excalidraw or draw.io into Notion-like tools, wikis, and documentation platforms.

- CRDT-based collaborative canvas libraries for building custom whiteboard experiences.

- Many self-hosted education and meeting whiteboard solutions released as open source.



**Frameworks for building custom systems**: Start with **Excalidraw** for the most popular open, hand-drawn whiteboard experience. Use **draw.io** when you need precise technical diagramming. Choose **AFFiNE** if you want whiteboard + documents in one local-first workspace. Embed **tldraw** or Excalidraw components when building whiteboard features into your own product (verify current licenses).

## Disclaimer



- This is a **community-curated** list — not exhaustive and not an endorsement.

- Collaborative whiteboards often handle sensitive workshop and strategy content. Self-hosted open-source tools give full data control but require you to manage real-time collaboration infrastructure, persistence, and access control. Commercial platforms typically offer richer facilitation templates, enterprise admin features, and polished multiplayer experiences out of the box.

- Always review current licenses (especially for libraries intended for embedding) before production use.
