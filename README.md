# Awesome-Scheduling

## Top Scheduling Tools Ecosystem



**Curated List of SaaS/Commercial Products & Open-Source GitHub Projects**  

*Focused on Appointment Booking, Meeting Scheduling, Availability Sharing, Team Round-Robin & Calendar Automation*  

**Last updated: August 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **Scheduling**. These tools help individuals and teams share availability, book meetings or appointments, manage event types, reduce back-and-forth emails, and integrate with calendars and video platforms.



**Examples** include Calendly, SavvyCal, Cal.com, YouCanBookMe, OnceHub, Doodle, SimplyBook.me, Acuity Scheduling, Bookafy, and Zoho Bookings (the category leaders).



**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosted scheduling and booking — ideal for privacy-conscious users, teams that want full data ownership, and organizations avoiding per-seat SaaS fees.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms



- **[Calendly](https://calendly.com/)**  

  The most widely used scheduling platform for sharing availability, booking meetings, team round-robin, workflows, and deep calendar/CRM integrations.



- **[SavvyCal](https://savvycal.com/)**  

  Modern scheduling tool emphasizing personalized booking links, overlay calendars, and a refined user experience for one-on-one and team meetings.



- **[Cal.com (Hosted)](https://cal.com/)**  

  Hosted version of the popular open-source scheduling platform, offering polished booking pages, team features, and integrations without self-hosting.



- **[YouCanBookMe](https://youcanbook.me/)**, **[OnceHub](https://www.oncehub.com/)**, **[Acuity Scheduling](https://acuityscheduling.com/)** (Squarespace)  

  Established booking and appointment platforms used by consultants, service businesses, and teams for client-facing scheduling.



- **[Doodle](https://doodle.com/)**  

  Popular group scheduling and polling tool for finding mutually available times across multiple participants.



- **[SimplyBook.me](https://simplybook.me/)**, **[Bookafy](https://www.bookafy.com/)**, **[Zoho Bookings](https://www.zoho.com/bookings/)**  

  Additional appointment and service booking platforms with features for businesses, multi-staff scheduling, payments, and ecosystem integrations.



## Open-Source GitHub Projects



- **[Cal.com / Cal.diy](https://github.com/calcom/cal.com)**  

  Leading open-source scheduling infrastructure (originally Calendso). Provides Calendly-style booking pages, event types, team scheduling, round-robin, workflows, payments, and extensive integrations. Self-hostable; note that production Cal.com code and the community edition have diverged over time.



- **[Easy!Appointments](https://github.com/alextselegidis/easyappointments)**  

  Mature, fully open-source (GPL) web appointment booking system. Supports services, providers, customer management, email notifications, and Google Calendar sync — excellent for clinics, salons, consultants, and service businesses.



- **[Rallly](https://github.com/lukevella/rallly)**  

  Open-source group scheduling and polling tool (Doodle alternative). Lets participants vote on preferred times without requiring accounts for basic use; fully self-hostable.



- **[PodCal](https://podcal.eu/)**  

  Privacy-first open-source scheduling tool built on Solid Pods. Supports self-hosting, CalDAV sync, and data ownership with an MIT license.



- **[Nextcloud Calendar & related apps](https://github.com/nextcloud)**  

  Calendar and scheduling capabilities within the Nextcloud ecosystem, useful for teams already running Nextcloud who want integrated availability and booking features.



- **[Thunderbird Appointment](https://appointment.day/)** and similar community tools  

  Open-source or source-available scheduling helpers focused on availability sharing and simple booking flows.



- **[Tymeslot and other emerging schedulers](https://github.com/)**  

  Newer privacy-oriented or source-available meeting scheduling platforms that emphasize self-hosting and data control.



### Additional Strong Open-Source Options



- Custom booking front-ends built on top of CalDAV/iCal and open calendar servers.

- Form + calendar automation stacks (e.g., combining open form tools with calendar APIs).

- Lightweight availability pages generated from static site generators or simple scripts.

- Many self-hosted appointment plugins for WordPress, ERPNext, and other open platforms.



**Frameworks for building custom systems**: For the closest Calendly experience self-host **Cal.com / Cal.diy** or **Easy!Appointments**. Use **Rallly** when the primary need is group availability polling. Combine any of these with CalDAV-compatible calendars, email/SMS gateways, and payment providers for a complete self-hosted scheduling stack.

## Disclaimer



- This is a **community-curated** list — not exhaustive and not an endorsement.

- Scheduling tools handle personal availability and sometimes payment or customer data. Self-hosted open-source solutions give full control but require you to manage uptime, security, calendar sync reliability, email deliverability, and backups. Review current project status and licenses carefully (some formerly fully open projects have shifted licensing or split community vs. production code).

- Always test calendar two-way sync and timezone handling thoroughly before relying on any system for critical bookings.
